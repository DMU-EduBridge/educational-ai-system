### 2. 교육용 문제 생성 ✅

**생성된 문제 예시**:

```
제목: 일차함수의 기울기와 y절편의 합 계산

문제: 다음 일차함수 `y - 3x = 4`에서 기울기와 y절편의 합은 얼마인가요?

선택지:
  1. 1
  2. 3
  3. 4
  4. 7 ✓ (정답)
  5. -1

해설: 
주어진 일차함수의 식은 y - 3x = 4입니다.
일차함수의 표준형은 y = ax + b이므로, 주어진 식을 이 형태로 정리해야 합니다.
y - 3x = 4의 양변에 3x를 더하면 y = 3x + 4가 됩니다.
이 식에서 a는 기울기를 나타내고 b는 y절편을 나타냅니다.
따라서 기울기 a = 3이고, y절편 b = 4입니다.
기울기와 y절편의 합은 3 + 4 = 7입니다.

힌트:
- 일차함수의 표준형인 y = ax + b 형태를 떠올려 보세요.
- 주어진 식을 y에 대해 정리하여 기울기(a)와 y절편(b)을 찾아야 합니다.

태그: 일차함수, 기울기, y절편, 방정식의 변형
```

- ✅ 명확한 문제 구성
- ✅ 상세한 해설 제공

### 1. LLMClient 비용 계산 버그
**문제**: `self.pricing['gpt-5-mini']` KeyError 발생  
**원인**: OpenAI 모델명을 기본값으로 사용  
**해결**: Gemini 기본값으로 변경

```python
# 수정 전
pricing = self.pricing.get(self.model_name, self.pricing['gpt-5-mini'])

# 수정 후
default_pricing = {'prompt': 0.00001875, 'completion': 0.000075}
pricing = self.pricing.get(self.model_name, default_pricing)
```
